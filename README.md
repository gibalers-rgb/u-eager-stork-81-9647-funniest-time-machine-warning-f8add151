A single one-line warning label for a time machine, 116 characters, written
to get the biggest laugh from a room of time travellers.

## The label

> WARNING: Do not approach yourself. If approached by yourself, remain calm. One of you is an imposter, and it is you.

## Why this line

- It is a genuine-looking safety notice, straight-faced and official.
- The hazard is real time-travel trouble: meeting your own duplicate self.
- The surprise is saved for the last three words — *and it is you* — so the
  laugh lands where the reader least expects it.
- Every phrase does work; nothing is wasted inside the 120-character limit.

## Run

```sh
python3 main.py
```

The program writes the label to `/output/entry.txt` by default, or to the
path in `OUTPUT_PATH`. Standard library only, deterministic, no network.
